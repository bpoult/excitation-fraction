bootstrap-darkly.min.css
    Bootswatch v5.3.6 "Darkly" theme (MIT), downloaded from
    https://cdn.jsdelivr.net/npm/bootswatch@5.3.6/dist/darkly/bootstrap.min.css
    -- the same URL as dash_bootstrap_components.themes.DARKLY in dbc 2.0.4.
    The Google Fonts @import (Lato) was removed so the app makes no network
    requests when run offline; the system font stack is used instead.

Dash serves every file in this folder at /assets/ and injects *.css into the
page automatically, so the theme works without internet access.
